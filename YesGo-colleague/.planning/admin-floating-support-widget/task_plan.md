## 约束与决策

- 复用 `ProAdminLayout`，同时覆盖总控后台和租户后台。
- 采用 Vue 3、TypeScript、Ant Design Vue 与 Vitest 现有技术栈。
- 不实现后端反馈工单、第三方在线客服、二维码或移动端组件。
- 当前 `.planning/.active_plan` 存在用户未提交改动，本轮不覆盖该文件。
- 客服电话与在线咨询地址先作为组件可选属性，由布局传入空值；不扩大为后端模型和迁移任务。
