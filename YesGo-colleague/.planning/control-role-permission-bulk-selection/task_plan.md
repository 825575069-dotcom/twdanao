# 角色权限树穿梭批量选择任务计划

## 目标

为角色权限树穿梭框增加全选和反选，语义与员工授权弹窗保持一致。

## 阶段

- [x] 阶段 1：以失败测试定义全选与反选行为
- [x] 阶段 2：实现左侧树工具条和选择处理
- [x] 阶段 3：执行定向、全量测试与构建并提交
- [x] 阶段 4：用内置浏览器复现树节点选中失效，并为树与穿梭框补齐受控选择状态

## 约束

- 不改动后端和保存接口。
- 批量操作仅改变待转移选择，不直接保存。
- 保留节点标题与复选框点击。

## 错误记录

- 初次组合补丁因代码围栏内容缺少补丁前缀而被拒绝；已改为拆分写入，不重试同一格式。
