# 定时任务与执行日志

## 目标

在现有多租户平台中实现可创建、管理和查询的定时任务，并为每次触发保留可按租户隔离查询的执行日志。

## 阶段

| 阶段 | 状态 | 说明 |
|---|---|---|
| 1. 现状调研与需求澄清 | 已完成 | 已确认仅总控可管理，支持受限 Shell/脚本与秒级 Cron。 |
| 2. 设计确认与设计文档 | 已完成 | 用户已确认秒级 Cron、总控权限与日志命名。 |
| 3. 实施计划 | 已完成 | 已写入并自检按 TDD 拆分的实施计划，等待执行方式确认。 |
| 4. 后端 TDD 实现 | 待开始 | 模型、服务、接口、调度入口及日志。 |
| 5. 前端 TDD 实现 | 待开始 | 租户后台任务管理与日志页面。 |
| 6. 完整验证与收尾 | 待开始 | 全量验证、迁移检查和状态检查。 |

## 约束

- 租户数据必须由后端强隔离，租户接口读取并校验 `X-Tenant-ID`。
- 首期任务、日志与状态机必须归属领域模块，入口层只负责鉴权和编排。
- 新增表结构、迁移和初始化脚本需同步；默认 `db_constraint=False`。
- 新行为必须先写失败测试，再实现最小代码。
