# 管理后台交互与头像上传修复计划

## 目标

统一移除管理后台用户可见提示和帮助文案的末尾句号，修复系统设置上传配置的表单冒号，补齐加载态与下拉搜索，并修复个人中心头像上传。

## 阶段

- [x] 1. 调查现有公共组件、上传认证路径及受影响页面
- [x] 2. 先写覆盖上传、加载和下拉搜索的失败回归测试
- [x] 3. 实施最小前后端修复与文案规范调整
- [x] 4. 执行定向、全量前后端验证并记录结果

## 约束

- 不修改用户已有的 `docker/compose.yml` 改动
- 用户可见的提示、帮助与说明文案不保留句号
- 下拉框使用 Ant Design Vue 原生 `show-search`
- 异步初始加载和刷新必须有可见 loading
