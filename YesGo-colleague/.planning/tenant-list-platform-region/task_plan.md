## 约束与决策

- 默认简体中文沟通和记录。
- 保留现有用户改动，不执行破坏性 Git 操作。
- 新行为测试先行，必须观察 RED 后再写生产代码。
- 租户与 `TenantPlatform` 保持一对一；数据库关系继续 `db_constraint=False`。
- 列表默认展示 ID，并按 ID 倒序；空状态为“暂无数据”。
- 编辑页沿用系统设置的左右分栏信息架构。
- 区域控件按通用组件设计，可由业务方配置使用 1 至 4 级。
- 总控 API 入口统一使用 `/api/control/`；前端租户资源使用全单数路径：`tenant`、`tenant/member`、`tenant/package`。
