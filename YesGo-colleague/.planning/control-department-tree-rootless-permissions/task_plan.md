## 关键问题

1. 已启用且未删除的总控账号可在无任何角色时登录；未绑定角色时保留空侧栏，不授予菜单访问权（已确认）。
2. 部门树是否应保留当前筛选、分页与操作能力，并以父子缩进方式展示？
3. 是否存在历史数据、迁移或初始化 SQL 仍依赖 `control-root`？

## 决策记录

| 决策 | 理由 |
|---|---|
| 暂不修改业务代码 | 先完成现状核查和用户确认，避免把“可登录”误解为绕过账号状态或后台权限。 |
| 无角色账号保留空菜单 | 用户明确确认登录与菜单授权分离；不因登录成功扩大权限。 |
| 设计说明单独提交 | 索引存在用户已有暂存内容，使用 `git commit --only -- <spec>` 仅提交本说明。 |
