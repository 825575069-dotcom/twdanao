# 租户套餐与智能体算力

## 目标

完成总控后台的租户套餐能力：套餐定义可选购的智能体及每个智能体的算力配额，并可分配给租户，在后端强制执行。

## 阶段

- [x] 1. 勘查现有租户、智能体、总控菜单与接口边界
- [x] 2. 与用户确认套餐的计量与生命周期规则，形成设计
- [x] 3. 按测试先行完成后端模型、领域服务与总控 API
- [x] 4. 完成总控后台套餐管理、租户订阅与用量界面
- [ ] 5. 完成独立审查、全量后端/前端与 Git 状态验证

## 关键决策

- 套餐按智能体配置月度 Token 额度；按租户套餐生效日起逐月重置，订阅包含生效与到期时间。调用完成后以 Dify `total_tokens` 最终结算。
