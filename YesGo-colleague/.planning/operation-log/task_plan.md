# 系统操作日志实施计划

## 目标

实现独立于运行诊断日志的系统操作审计：自动记录已认证请求的成功写操作，并提供总控只读查询接口和操作日志页面。

## 阶段

- [x] 1. 确认范围与既有日志边界
- [x] 2. 完成方案设计并等待规格审阅
- [x] 3. 编写实施计划与测试清单
- [ ] 4. 测试先行实现数据模型、采集和查询 API
- [ ] 5. 接入总控页面并完成全量验证

## 关键约束

- `SystemLog` 保持运行诊断用途；操作审计独立建模。
- 只采集已认证且成功的写请求；登录日志继续使用既有登录日志领域。
- 审计记录不可编辑、不可删除；敏感字段和值绝不落库。
- 总控可跨租户查询，租户端不开放完整操作日志读取。
