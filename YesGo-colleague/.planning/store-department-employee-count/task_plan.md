# 门店列表部门员工统计与跳转

## 目标

在门店列表的部门名称后展示该部门员工数；点击数字后进入员工列表，并按对应部门预筛选。

## 阶段

- [completed] 1. 调研部门列表、员工列表、路由和数据接口
- [completed] 2. 明确交互设计并取得用户确认
- [completed] 3. 编写并确认实现计划
- [completed] 4. 测试先行实现统计展示和部门筛选跳转
- [completed] 5. 运行相关测试、构建与 Git 状态检查
- [completed] 6. 修复部门列表状态字段的中文枚举展示
- [completed] 7. 修复角色权限配置无法点击并完成前端验证

## 约束与决定

- 沿用现有 Vue 3、Ant Design Vue 与路由约定。
- 不修改无关的用户改动。
- 优先使用现有员工列表筛选字段和后端统计数据；若缺失，最小范围补齐。
- 已由用户确认“门店列表”实为总控“部门管理”页面。
- 动态统计定义为每次部门树请求实时聚合直属且未删除员工数。
- 状态展示应使用中文枚举值，与总控员工列表的“启用/停用”保持一致。
