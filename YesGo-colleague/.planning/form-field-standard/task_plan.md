# 表单字段标准化计划

## 目标

统一编辑和配置页面的中文标签、冒号、标签列宽度，以及文本输入长度计数规则。

## 阶段

- [x] 盘点现有编辑表单与数据库长度来源。
- [x] 设计并测试通用文本输入组件。
- [x] 接入总控、租户、个人中心和系统设置编辑表单。
- [x] 更新设置页与表单标准文档。
- [x] 运行定向测试、完整前端测试和构建检查。

## 决策

- 编辑/配置表单使用横向布局，标签列固定 `140px`，控件列自适应，显示中文冒号。
- 有数据库长度约束的文本输入显示计数；默认可输入字符数为数据库长度向下除以 3。
- 仅限英文的账号、编码、路径、URL、邮箱、手机号、密码、接口方法等字段使用数据库原长度。
