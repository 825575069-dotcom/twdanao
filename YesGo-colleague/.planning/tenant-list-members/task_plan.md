# 租户列表与成员完善计划

## 目标
完善总控后台租户列表与租户成员，成员从演示数据升级为真实接口，支持查询、新增、编辑、启用/禁用和角色分配。

## 阶段
- [completed] 1. 盘点现状并确定契约
- [completed] 2. 后端成员接口与测试
- [completed] 3. 前端租户列表与成员页面改造及测试
- [completed] 4. 全量验证与清理临时文件

## 决策
- 沿用 `/api/control/` 总控入口与标准响应外壳。
- 成员以 `TenantUser` 为主表，角色通过 `TenantUserRole` 关联。
- 不删除用户；状态切换通过 `status` 字段完成。
- 租户成员详情页特化为真实接口表单，其它通用资源仍保持占位/演示式详情。
