# 头像上传失败排查计划

## 目标

定位并修复当前头像上传失败的根因，补充回归测试并完成相关验证。

## 追加目标

实现头像的本地预览、保存时上传和上传加载状态；上传失败后保留待提交头像以便重试。

## 阶段

1. [已完成] 收集前后端请求、认证、OSS 配置和近期变更证据。
2. [已完成] 对照可用模式，确认根因并编写失败回归用例。
3. [已完成] 实施单一针对性修复。
4. [已完成] 运行后端、前端及迁移验证，检查工作区状态。
5. [已完成] 调整头像交互并补充前端回归测试。
6. [已完成] 初始化本地运行环境并启动前后端服务，供手动验收。
7. [已完成] 处理资料表单的字段级校验提示与控件定位。
8. [已完成] 将字段级校验错误的提示和定位能力抽为可复用机制，并应用到资料、角色、权限、部门和员工表单。
9. [进行中] 合并套餐功能分支前，修复当前 dev 的既有测试断言漂移并完成合并验证。
